# Decisions

Why the kit is built the way it is. One file per decision: the question, what
was chosen, why, and what would change the answer.

| # | Decision |
|---|---|
| [0001](0001-copier-template.md) | Distribute the kit as a copier template, not a custom installer |
| [0002](0002-native-suppressions.md) | Record existing debt with each tool's own baseline, not a custom ratchet |
| [0003](0003-no-reusable-workflows.md) | Render the CI workflow into the repo instead of calling reusable workflows |
| [0004](0004-modules-and-presets.md) | Independent modules with presets, not ordered levels |
